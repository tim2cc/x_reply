# X Accessible Auto Replier

Отдельное Manifest V3-расширение для X, рассчитанное на пользователя, которому трудно физически подтверждать каждое действие)

## Режимы

- `Черновик`: ответ генерируется и вставляется в composer, публикация вручную.
- `Подтверждение`: перед публикацией требуется отдельное подтверждение.
- `Автоматический`: публикация выполняется без подтверждения для разрешённых целей.

Автоматический режим ограничен дневным лимитом, задержками, cooldown на автора, аварийной остановкой и policy-фильтрами. Автолайки, автофоллоу, DM и stealth-механики отсутствуют.

## Установка

1. Создать API key в OpenRouter: `https://openrouter.ai/settings/keys`.
2. Открыть `chrome://extensions`.
3. Включить Developer mode.
4. Load unpacked → выбрать эту папку.
5. Открыть настройки расширения.
6. Нажать `Использовать OpenRouter Free`, вставить ключ и сохранить.

AI-конфигурация хранится локально. По умолчанию используется OpenRouter Free Router:

```text
Endpoint: https://openrouter.ai/api/v1
Path: /chat/completions
Model: openrouter/free
```

OpenRouter предоставляет бесплатные модели с ограниченными квотами; доступность и лимиты зависят от текущих условий сервиса. Для конкретной бесплатной модели можно указать её slug с суффиксом `:free`.

Для локального Hermes можно заменить endpoint на `http://127.0.0.1:8642`, а path на `/v1/chat/completions`.

## Ограничения MVP

Сбор целей идёт из видимых карточек X. Поддерживаются оригинальные посты, упоминания и ручной сбор текущей ленты. DOM X нестабилен; при изменении интерфейса расширение останавливает автоматический цикл вместо попытки действовать вслепую.
